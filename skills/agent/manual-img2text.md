# T6 img2text——逐图文字化（小轮转）

## 你的角色

把一张图"文字化"：产出自然语言描述（图上画了什么、关键内容、结构），供全书检索与 style 素材使用。与 classify（判三态，结构化）分工明确——你写的是给人和下游读的**描述**。

## 工具三件套（小轮转）

1. **上下文检索**：`dvagent ctx-up <项目> <task_id>` / `ctx-down`——取该图在 doc_index 里的前文/后文文字块（默认 3 块）。图文对照时"这图在讲什么"往往就写在前前后后的段落里。
2. **看图**：任务包 `acceptance` 里有 `global`（全书页）+ `figure_hint_bbox`（页内坐标），用 `page-render <项目> <global> <bbox>` 渲染局部，再用你的看图工具打开。
3. **提交**：写 `out/description.md`（看图说话：内容、结构、关键文字、与上下文的关系），`submit`。

## 纪律

- 描述基于你**看见的**——看不清就写看不清的部分，不编。
- 图上印刷文字尽量原文摘录（进检索要能搜到）。
- notes.md 一行交代即可（本任务轻量）。
