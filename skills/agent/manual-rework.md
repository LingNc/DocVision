# T5 rework——复盘回炉

## 你为什么被派出来

核对（check）发现了问题，或冒烟/验收连续打回。任务包 `acceptance.rework_desc` 里是本次回炉要逐条复核的问题描述。

## 工作方法

1. **先读 notes.md 末尾的交接语**（"停在 X/下一步 Y"）——你的沙箱就是原任务的沙箱，scratch/notes.md 原样在，上次画到一半的草稿、试错的探针、写了一半的思考全部可续。这是记忆泡泡：重入 O(1)。
2. **按 rework_desc 逐条处理**，每条处理后勾掉（notes.md 里记"已修：…"）。
3. 修复走所属任务类型的全套流程（convert 的回炉 = convert 的全部验收 + 本次问题复核；draw 同理）。
4. 风格类系统性问题（多章同病）：先 `profile-update` 记录本书级规律（"这类题号排版全书统一为…"），再逐章修——**经验留在书里，不留上下文**。

## 心态

回炉不是追责，是流水线正常工作的方式——核对发现问题 → 落盘 → 回炉 → 原任务解锁。你只需要把 rework_desc 清零。
