# Figure Compare 目录规则

- 本目录是受版本控制的长期原型，**不可当作临时目录清理**；删除或迁移前必须向用户列出清单并取得确认。
- 代码分层：算法放 `algorithms/`，合成测试放 `tests/`，纯静态前端放 `viewer/`，设计文档放 `docs/`。
- 任何新增代码、测试、文档均不得包含真实书籍/项目/作者名称、真实样本描述、本机绝对路径、个人密钥、JSONL 会话内容或真实图像素材。隐私审查后再提交。
- 忽略规则不等于可以删除：`*.jsonl`、图像及指标结果均为数据，默认不进 Git；如要保存必须另行确认存放和隐私策略。
- 核心算法需保持可重复性；改动后运行 `PYTHONPATH=algorithms python3 -m unittest discover -s tests -v`。
- viewer 默认不呈现比较面板；载入会话后再显现。没有可用的比较图像产物时不得硬编码示例图片或固定本机路径。
- 新增功能或调整判定语义时更新 `README.md` 与 `docs/design.md`，并说明旧指标兼容性。
